# Nokia Emulator (Simulator) — Android project

This is a starter Android Studio project for a portrait Nokia Series 40-inspired interface.
It recreates the blue/teal standby/menu look and a touch keypad based on the supplied reference.

## Build
1. Install Android Studio with Android SDK Platform 35.
2. Open this folder (`NokiaEmulator`) in Android Studio.
3. Allow Gradle sync.
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Find the APK at `app/build/outputs/apk/debug/app-debug.apk`.

This archive contains project source, not a precompiled APK. The build requires Android Studio/Android SDK.
The icons are simplified drawn placeholders; this is a first working UI prototype, not a firmware emulator.
